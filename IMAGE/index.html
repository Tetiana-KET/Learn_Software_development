images are inline by default, that's why you may see a space beneath the image, which is for descender. This ia an the extra space that appears below an inline image due to how browsers handle inline elements. By default, images are treated as inline elements (like text). When an image is placed inside a container, browsers align it along the baseline of surrounding text. Since text characters like g, y, p, or q have descenders (the parts that go below the baseline), the browser leaves extra space for them—even if there’s no actual text.

    To remove this extra space use:
  1. display: block - This removes inline behavior and eliminates the extra space. img { display: block; }
  2. vertical-align: bottom - This ensures the image aligns with the bottom of its container instead of the text baseline. img { vertical-align: bottom; }

Fitting an image inside flexbox

Fitting images inside flexible boxes or flex box or display flex boxes works a little bit differently from grid. Flex will scale its child elements to 100% of the height of the flex container to create equal height columns by default. If an image height is set to auto? the image will automatically be stretched to the height of its container and as a result we get stretched images. To fix it, use object fit and set it to cover. Now the images fill out the available space of their containers

When you add a background image, it is automatically added in its full size. So what you're initially seeing will be actually just a top left corner of the whole background image. It is scaled to its full size, and then it's cropped by the container. If you want to resize this background image to make it fit within the container, use a background-size property.

The background-origin property controls where the background image or background color starts within an element. If you combine background-origin and background-size cover, you may get unexpected behavior. So this is something worth keeping in mind.

border-box
Background starts from the outer edge of the border (includes the border).
padding-box (default)
Background starts from the inner edge of the border (does not cover the border).
content-box
Background starts from inside the padding, covering only the content area (not padding or border).
